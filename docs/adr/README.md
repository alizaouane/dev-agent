# Architecture Decision Records

Location per Operating Standard §4.1: `/docs/adr/`.

Format: `NNN-kebab-title.md`, from `~/.bmad/templates/adr.template.md`. One
decision per file, numbered sequentially, never renumbered. A superseded ADR
stays in place with a `Superseded by NNN` header rather than being edited away.

One ADR per non-obvious decision, written by the Architect persona.
